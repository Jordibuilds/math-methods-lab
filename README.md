# Math Methods Lab

An interactive practice workbook for mathematical methods in business and economics. Its equation editor lets you enter fractions, roots, powers, and symbols using on-screen controls.

[Open the live demo](https://jordibuilds.github.io/math-methods-lab/)

- Work through 33 exercises across 11 chapters, with space for equations, matrices, cases, graphs, and notes.
- Request hints, check supported expressions, or compare written reasoning with a reference solution.
- Generate new numbers for eligible exercises and practise techniques such as differentiation and solving equations in Skills Practice.

Open `index.html` in a browser to run the workbook. The app is self-contained and runs without a build step.
